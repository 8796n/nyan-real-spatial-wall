nyan Real / Firmware Kit

Firmware Kit

Build verified, modified images locally from official firmware for display glasses and peripherals. The kit includes display and audio changes for use with Spatial Wall and peripheral compatibility fixes. It can also be used independently.

  • Modifying XREAL Air 2 / Air 2 Pro and bringing RGB to Air (Japanese)

Supported devices and requirements

  • XREAL Air (gen 1) / Air 2 / Air 2 Pro: native RGB output, 720p input, Full-SBS at 90 Hz and automatic DP audio without USB data. First-generation Air also supports 1920×1200 output.
  • MOKIN UC6101B docks: compatibility fixes for Nintendo Switch 2. The builder generates an image only; it does not flash the dock.

Requires Python 3.10 or later. Image builders run on Windows, macOS and Linux. Hardware flashing has been verified on Windows. See the README for model-specific instructions and verification scope.

Before using the kit

This is an unofficial project with no manufacturer affiliation. A failed firmware write can leave your device unable to boot. Understand the risks and read the README warnings before using the kit.

Neither official nor modified firmware is distributed, and instructions for obtaining official files are not provided. Keep a separate copy of your official files for recovery.

Do not flash first-generation XREAL Air if you use it with Nebula on Beam Pro: this build prevents it from proceeding past the startup screen. RGB output increases power consumption and is expected to increase heat.
