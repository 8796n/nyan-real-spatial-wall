Platforms

4つの環境をサポート

共通のSpatial Wallアプリを、各OSの画面・音声・入力の仕組みに合わせて提供します。

Windows

Windows単独版

Windows 10 build 19041以降、64bit。

 macOS

macOS版

macOS 14.4以降。現在は実験的対応です。

 Linux

GNOME版

GNOME 46以降のWaylandセッション。

 Raspberry Pi

Pi / labwc版

Raspberry Pi OS trixie以降。

問い合わせ前に「問い合わせ用情報をコピー」

Spatial Wallの「バージョン情報」を開き、「問い合わせ用情報をコピー」を押してください。バージョン、ビルド時刻、接続中のメガネがまとまり、問い合わせフォームへそのまま貼り付けられます。
