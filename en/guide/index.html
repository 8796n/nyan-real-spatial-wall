Platform guide

Install for your OS

Package names can change between releases. Use the current package supplied through your purchase or distribution channel.

Windows standalone

Requirements: 64-bit Windows 10 version 2004 (build 19041) or later, plus a video-capable USB-C port or a suitable HDMI adapter.

  1. Run *-windows-x64-installer.exe, or extract the portable ZIP and launch spatial-wall.exe.
  2. If SmartScreen appears for an unsigned package, verify where the file came from before choosing More info → Run anyway.
  3. Connect the glasses as an extended display. “Force glasses to an extended display” can repair a disabled or duplicated display on connection.

HMD-capable modes: direct output is conditional and currently limited to selected EDID/hardware combinations. If a display remains dark, disable saved-mode restoration, reconnect it, and restart Windows if necessary.

macOS

Requirements: macOS 14.4 or later. The macOS edition is currently experimental; check the supplied README for the supported architecture and signing status.

  • Screen capture requires Screen Recording permission.
  • The cursor fence needs Input Monitoring; input injection needs Accessibility.
  • Restart the app after changing a permission.

Control+Shift+Esc turns the master off on macOS, providing an escape from the warped output or a stranded cursor.

Linux / GNOME

Requirements: GNOME 46 or later in a Wayland session. X11 sessions are not supported.

  1. Obtain the GNOME-specific .deb; it is different from the Pi package.
  2. Install it with sudo apt install ./package-name.deb.
  3. Log out and back in, then start Spatial Wall from the app menu.

Virtual displays use GNOME/Mutter's built-in screen-casting facilities. Wayland does not permit a global cursor fence, forced movement of other apps' windows or interception of Print Screen.

Raspberry Pi / labwc

Requirements: Raspberry Pi OS trixie or later with labwc. Use the dedicated Pi .deb.

  1. Copy the Pi package to the device.
  2. Install it with sudo apt install ./package-name.deb.
  3. Restart to apply USB access and labwc integration.

The Pi package includes glasses USB-power monitoring and labwc virtual-display integration. Do not install the GNOME package on the Pi.

Every platform

  • Use a USB cable that carries both video and data.
  • The app performs no automatic update check, telemetry or crash reporting.
  • See the user manual for operation and troubleshooting.
